# Git Workflow

## 基本方針

- Git操作の対象を明示する。
- 無関係な変更をコミットに含めない。
- 単一ファイルの変更点は、ユーザーが細分化を明示しない限り、そのまま1コミットにする。
- 複数ファイルにまたがる変更は、ファイル単位または意味のまとまり単位でコミットする。
- コミット以外のGit操作でも、対象外の変更を巻き込まない。

## コミットメッセージ

- コミットメッセージはConventional Commits形式を使用する。

## 確認

- Git操作前に作業ツリーの状態を確認する。
- コミット前にステージ済み差分を確認する。
- コミット後に直近の履歴と作業ツリーの状態を確認する。
